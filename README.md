# Python Day 169 – Personal Finance Report Generator

## Project Description
A Python application that records income and expenses, calculates the remaining balance, and generates category-wise financial reports.

## Features
- Add income and expense transactions
- Store records in CSV format
- View transaction history
- Calculate total income and expenses
- Generate category-wise expense summaries
- Export reports to a text file

## Technologies Used
- Python
- CSV
- Collections
- File Handling

## Files
- `finance_report.py` – Main program
- `transactions.csv` – Transaction records (created automatically)
- `finance_report.txt` – Generated report

## How to Run
`python finance_report.py`

## Concepts Learned
CSV handling, dictionaries, functions, file operations, validation and report generation.
